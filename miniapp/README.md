# 铜锅涮肉微信小程序

这是一个独立于现有 `frontend/` Web 管理端的原生微信小程序工程，当前优先覆盖顾客扫码点餐链路：

- 入口页：扫码 / 手输桌号，支持手机号可选登录
- 菜单页：分类筛选、搜索、购物袋、备注、提交订单
- 进度页：查看当前桌台订单和上菜状态，10 秒自动刷新
- 我的页：手机号会员信息、消费记录、积分明细

## 目录

- `app.*`：小程序全局配置
- `pages/entry`：扫码落座入口
- `pages/menu`：点餐主页面
- `pages/status`：上菜状态
- `pages/mine`：会员信息
- `api/`：对接后端 `/api/c/*`
- `utils/config.js`：接口地址配置

## 本地运行

1. 用微信开发者工具打开 `miniapp/`
2. 把 `utils/config.js` 里的 `API_BASE_URL` 改成你的后端地址
3. 启动后端服务
4. 在开发者工具中访问入口页，带上 `tableId` 参数调试

示例：

- 直接打开入口页，然后输入桌号
- 或者通过二维码 / 页面参数传入 `tableId=1`
- `scene` 也支持直接传桌号，或 `tableId=1`

## 真机调试注意

- 真机不能用 `127.0.0.1` 访问你电脑上的 Java 服务
- 请改成同一局域网下可访问的 IP，例如 `http://192.168.1.100:8080`
- 微信后台还需要把接口域名加入合法域名白名单
